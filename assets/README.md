# Assets

This directory contains app assets including:

- `icon.png` - App icon (1024x1024)
- `splash.png` - Splash screen image
- `adaptive-icon.png` - Android adaptive icon (1024x1024)
- `favicon.png` - Web favicon (48x48)

## Notes

For development, you can use placeholder images. For production, replace these with proper branded assets.

To generate proper icons from a single image, you can use tools like:
- https://www.appicon.co/
- https://icon.kitchen/
